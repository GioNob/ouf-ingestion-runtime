# R3 — incident timeline and bounded catch-up

Baseline: Ingestion PET v1.3 §46, MCP PET v1.4 §33, Gateway operational-awareness contract. This increment covers persistent incidents and incident catch-up; it does not declare all R3 matrix gaps closed.

The Inspector client used for latency diagnosis is temporary test equipment. It is not a production Keycloak configuration or a prerequisite of this implementation.

Deployment requires coordinated review of all three branches. No production deployment or merge is performed by this change.

## Owner persistence and recovery

V15 adds owner-local incident and immutable transition tables. Run/partition failures and runtime issues write evidence in the same database transaction. Transient execution and preflight retries retain the run/incident identity, publish RECOVERING and next retry time, enforce pinned attempt/elapsed budgets, and remain OPEN on terminal failure. Successful draining resolves run incidents with duration and a safe outcome; independent runtime issues retain their governed resolution workflow. Scheduler misfire is explicit evidence.

Incident pages use an immutable sequence watermark and fixed time window, with source, run, state and severity filters. Limits are 1–100 and cursors expire after 15 minutes. Every page re-evaluates owner authorization; restricted evidence is redacted and partial. Explain reads at most 200 transitions and marks truncation. Existing run-history behavior is not extended by this increment.

Retention maintenance is explicit, bounded to 100 resolved incidents, with a 30-day minimum and the pinned longer policy. Open/recovering incidents, incident holds, run lineage, audit references and active historical-contract holds prevent deletion. No automatic cleanup schedule is introduced.

## Verification

IncidentTimelineRuntimeTest covers retry identity, budgets, stale-worker fencing, transaction rollback, stable pagination through state changes, per-page authorization, immutable transitions and retention. ActivationLeaseRuntimeTest covers preflight retry identity and misfire. Existing worker and authorization tests remain gates. The PostgreSQL 17 dump/restore CI drill now checks incident identity, state and transition alongside run, snapshot, watermark, quarantine and outbox.

Local integration tests use PostgreSQL-compatible PGlite 18.3 with real JDBC and all SQL migrations; native PostgreSQL 17/Flyway/container/restore validation remains the CI gate. Shared incident receipts are generated by the actual Gateway Lua and checked by both Java producers, including scope, revocation, body integrity, expiry and tenant mismatch.
